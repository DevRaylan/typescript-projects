# Desafio Prático

Projeto em TypeScript com implementação de algoritmos de Fibonacci e números primos nas versões recursiva e linear.

## Instalação e execução

```bash
npm install
npm run build
npm start
```
## Estrutura do projeto

```txt
src/
├── fibonacci.ts
├── primes.ts
└── main.ts
```

## Exemplos de saída
```bash
fib recursiva 0: 0
fib recursiva 1: 1
fib recursiva 2: 1
fib recursiva 3: 2
fib recursiva 5: 5
fib recursiva 6: 8
fib linear 0: 0
fib linear 1: 1
fib linear 2: 1
fib linear 3: 2
fib linear 5: 5
fib linear 6: 8
primos recursivo 2: [ 2 ]
primos recursivo 3: [ 2, 3 ]
primos recursivo 10: [ 2, 3, 5, 7 ]
primos linear 2: [ 2 ]
primos linear 3: [ 2, 3 ]
primos linear 10: [ 2, 3, 5, 7 ]
```
