# Desafio Prático SC Clouds

Este repositório reúne os projetos desenvolvidos para o desafio prático da SC Clouds.

Cada pasta contém um projeto independente, com sua própria implementação, estrutura e instruções de execução.

Para rodar qualquer projeto, acesse a pasta correspondente e consulte o `README.md` interno, onde estão descritos os passos necessários para instalação, build e execução.
