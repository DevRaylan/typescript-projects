# Desafio Prático com Interface

Esta versão do projeto possui:

- Cálculo de Fibonacci com versão recursiva e linear.
- Cálculo de números primos com versão recursiva e linear.
- Validação de entrada para evitar valores inválidos.
- Interface web simples para testar os algoritmos.
- Botões de calcular e limpar.
- Mensagens visuais de sucesso, erro e estado neutro.
- Estilo visual inspirado na identidade da SC Clouds.

## Como executar

1. Acesse a pasta do projeto:
   ```bash
   cd desafio-pratico-com-interface
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Execute o projeto:
   ```bash
   npm start
   ```

## Scripts disponíveis

- `npm run build`  
  Compila o projeto TypeScript.

- `npm run serve`  
  Inicia o servidor local e abre o projeto no navegador.

- `npm start`  
  Executa o build e inicia o servidor automaticamente.

## Acesso

Após iniciar, o projeto será aberto automaticamente no navegador.  
Caso isso não aconteça, acesse manualmente:

```bash
http://localhost:3000/public/index.html
```
